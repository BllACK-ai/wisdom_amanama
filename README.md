# portfolio-react

Vite + React + TypeScript. Edit your content in `src/data.ts`.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # type-checks, then outputs dist/

Structure: `src/App.tsx` (page), `src/components/` (Sidebar, ItemList), `src/hooks/` (scroll-spy nav, cursor spotlight), `src/styles.css` (design tokens, light/dark).
